# 💰 동동구 (dongdong9) - 부부 예산 관리 앱

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

동동구는 부부가 함께 현명한 소비와 절약을 실천할 수 있도록 돕는 스마트한 예산 관리 애플리케이션입니다. 공동의 예산을 설정하고, 각 카테고리별로 지출을 할당하며, 모든 소비 내역을 손쉽게 기록하여 효율적인 재정 관리를 지원합니다.

## ✨ 주요 기능

*   **간편한 로그인 & 회원가입**: Google 🌐 및 Apple 🍎 계정을 통해 빠르고 안전하게 앱을 시작할 수 있습니다.
*   **가계부 생성 및 참여**:
    *   새로운 가계부를 생성하여 우리 부부만의 재정 관리를 시작하세요! 👨‍👩‍👧‍👦
    *   초대 코드를 통해 기존 가계부에 참여하여 배우자와 함께 예산을 관리할 수 있습니다. 🤝
*   **유연한 예산 설정**:
    *   월별 총수입을 설정하여 전체적인 재정 흐름을 한눈에 파악합니다. 💸
    *   월세, 통신비 등 고정적으로 발생하는 지출 항목을 추가하고 체계적으로 관리하세요. 🏠
*   **세분화된 지출 카테고리 관리**:
    *   식비 🍔, 교통비 🚌, 문화생활비 🎭 등 다양한 지출 카테고리를 자유롭게 생성할 수 있습니다.
    *   각 카테고리 아래에 하위 카테고리를 추가하여 더욱 정교하고 세밀한 예산 관리가 가능합니다. 📊
*   **직관적인 예산 현황 대시보드**:
    *   설정된 총수입, 고정 지출, 그리고 현재 사용 가능한 예산을 시각적으로 명확하게 보여주는 대시보드를 제공합니다. 📈
*   **안전한 계정 관리**:
    *   언제든지 간편하게 로그아웃할 수 있습니다. 🚪
    *   필요 시 회원 탈퇴를 통해 모든 계정 정보를 안전하게 삭제할 수 있습니다. 🗑️

## 🛠️ 기술 스택

*   **프레임워크**: SwiftUI
*   **아키텍처**: MVVM (Model-View-ViewModel)
*   **백엔드**: Firebase (Authentication, Firestore)
*   **인증**: Google Sign-In, Apple Sign-In

## 🚀 시작하기

### 📋 전제 조건

*   Xcode 15.0 이상
*   iOS 17.0 이상
*   Firebase 프로젝트 설정 및 `GoogleService-Info.plist` 파일 연동

### ⚙️ 설치

1.  이 저장소를 클론합니다:
    ```bash
    git clone https://github.com/wangkobong/dongdong9.git
    ```
2.  프로젝트 디렉토리로 이동합니다:
    ```bash
    cd dongdong9
    ```
3.  Xcode에서 `dongdong9.xcodeproj` 파일을 엽니다.
4.  Firebase 프로젝트에서 다운로드한 `GoogleService-Info.plist` 파일을 프로젝트의 `dongdong9` 폴더에 추가합니다.
5.  필요한 경우, Xcode에서 프로젝트의 Bundle Identifier 및 팀 설정을 업데이트합니다.
6.  앱을 빌드하고 실행합니다.
